# Allemando — Agent notes

Static Astro site for Allemando Institut. No backend, database, or form storage.

## Rules for this project

- Prefer verified public facts; mark unconfirmed branch details clearly.
- Do not invent prices, durations, visas guarantees, or fake testimonials.
- French (`/fr/`) is the only published locale in V1.
- Enrollment is via mailto / social / WhatsApp (when `whatsappNumber` is set in `src/config/site.ts`).
- Deploy by uploading `dist/` to Namecheap `public_html`.
